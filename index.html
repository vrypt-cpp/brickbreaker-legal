BrickBreaker Bot

Automated YouTube Shorts generator

BrickBreaker Bot is a personal automation tool that generates short vertical gameplay videos and publishes them to a single YouTube channel using the YouTube Data API v3.

What it does

  • Simulates a brick-breaker game with a deterministic bot player.
  • Renders a 1080x1920 video from the simulation.
  • Uploads the result to the owner's own YouTube channel.

It accesses only the account of its operator. It does not read, store or process any third-party user data.
